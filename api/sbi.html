LFIRE — Likelihood-Free Inference by Ratio Estimation (Thomas et al. 2022, Bayesian Analysis 17, 1).

For a parameter value theta, simulated data from p(x | theta) and from the marginal p(x) (prior predictive) are separated with a logistic-regression classifier. Its log-odds estimate the log density ratio

log r(x, theta) = log p(x | theta) - log p(x),

so p(theta | x_obs) ∝ prior(theta) * r(x_obs, theta). Each evaluation costs n_theta simulations plus one classifier fit, so LFIRE either evaluates a grid directly (low dimensions) or learns a GP surrogate of the log ratio with Bayesian optimisation and samples that, as in BOLFI.

Examples

>>> lfire = LFIRE(simulator, x_obs, {'mu': (0, 3), 'sigma': (0.1, 2.5)}, summary=my_summaries)
>>> lfire.learn_posterior(n_calls=60)
>>> samples = lfire.sample_posterior(5000)
class psiphy.sbi.lfire.LFIRE(simulator, observation, prior, n_m=500, n_theta=500, summary=None, penalty='l1', classifier=None, acquisition='UCB', clip_log_ratio=20.0, bounds=None, param_names=None, n_jobs=1, random_state=None, verbose=True)[source]

Likelihood-free inference by ratio estimation.

Parameters:

  • simulator (callable) – simulator(theta) -> x (array-like).

  • observation (array-like) – Observed data, in the same format as the simulator output.

  • prior (list of (low, high), dict name -> (low, high), or prior object)

  • n_m (int) – Simulations from the marginal (prior predictive), drawn once and reused.

  • n_theta (int) – Simulations at each parameter value evaluated.

  • summary (callable, optional) – summary(x) -> 1-D features used by the classifier. Defaults to the flattened data. The log ratio is linear in these features, so include nonlinear terms (e.g. squares) when the data distribution changes shape with theta.

  • penalty ({"l1", "l2"}) – Regularisation of the default classifier (cross-validated). "l1" follows the paper and selects among many candidate summaries; "l2" is several times faster when there are few summaries.

  • classifier (sklearn classifier, optional) – Replaces the default; must provide decision_function (log-odds). It is cloned for every evaluation.

  • acquisition ({"UCB", "EI", "PI"} or callable) – Acquisition for learn_posterior() (maximising the log ratio).

  • clip_log_ratio (float or None) – The GP surrogate is fitted to max(log_r, max(log_r) - clip_log_ratio). Far from the posterior the classes separate perfectly and the log ratio becomes hugely negative (limited only by regularisation); without the floor those values dominate the GP and widen the posterior. Points below the floor carry less than exp(-clip_log_ratio) of the peak posterior density. None disables it.

  • bounds (list of (low, high), optional) – Search box; defaults to the prior bounds.

  • param_names (list of str, optional)

  • n_jobs (int) – Workers for the classifier’s cross-validation.

  • random_state (int, optional) – Seed for the classifier.

  • verbose (bool)

BOLFI — Bayesian Optimisation for Likelihood-Free Inference.

A Gaussian-process surrogate of the discrepancy d(theta) between simulated and observed data is learned with Bayesian optimisation (Gutmann & Corander 2016). The synthetic log-likelihood log K(d_hat(theta)) is then sampled with any of the psiphy samplers (emcee, nested sampling, importance sampling, SMC).

Examples

>>> bolfi = BOLFI(distance_fn, {'mu': (-5, 5), 'sigma': (0.1, 5)})
>>> bolfi.learn_likelihood(n_calls=100)
>>> samples = bolfi.sample_posterior(5000, method='MCMC')
class psiphy.sbi.bolfi.BOLFI(distance, prior, distance_kernel='exp', acquisition='LCB', learn_log_dist=False, n_repeats=1, bounds=None, param_names=None, verbose=True)[source]

Bayesian Optimisation for Likelihood-Free Inference.

Parameters:

  • distance (callable) – distance(theta) -> float: simulate at theta and return the discrepancy to the observed data.

  • prior (list of (low, high), dict name -> (low, high), or prior object) – Bounds are converted to a UniformPrior. A prior object must expose mins/maxs unless bounds is given.

  • distance_kernel ({"exp", "gaussian"} or callable) – Maps the discrepancy to a log-likelihood. A callable must have signature log_kernel(d) -> log L.

  • acquisition ({"LCB", "EI", "PI"} or callable) – Acquisition function choosing where to simulate next; see psiphy.utils.bayesian_opt. "LCB" follows Gutmann & Corander (2016).

  • learn_log_dist (bool) – Model log d instead of d (helps when d spans orders of magnitude).

  • n_repeats (int) – Distance evaluations (simulations) averaged per parameter value. With a stochastic simulator each d(theta) is noisy; averaging n of them cuts the noise variance by n and makes the GP surrogate, and the posterior widths, more stable from run to run. The simulations at one theta are independent, so they can run in parallel. The extra noise in a single-simulation d adds a roughly constant offset that cancels in the normalised posterior.

  • bounds (list of (low, high), optional) – Search space for the optimisation; defaults to the prior bounds.

  • param_names (list of str, optional)

  • verbose (bool)

  • n_candidates (int, optional) – Random candidates scored per pick (default 1000 * n_dim).

  • **acq_kwargs – Acquisition options, e.g. kappa (LCB) or xi (EI/PI).

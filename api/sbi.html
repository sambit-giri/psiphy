docstring for LFIRE

BOLFI — Bayesian Optimisation for Likelihood-Free Inference.

A Gaussian-process surrogate of the discrepancy d(theta) between simulated and observed data is learned with Bayesian optimisation (Gutmann & Corander 2016). The synthetic log-likelihood log K(d_hat(theta)) is then sampled with any of the psiphy samplers (emcee, nested sampling, importance sampling, SMC).

Examples

>>> bolfi = BOLFI(distance_fn, {'mu': (-5, 5), 'sigma': (0.1, 5)})
>>> bolfi.learn_likelihood(n_calls=100)
>>> samples = bolfi.sample_posterior(5000, method='MCMC')
class psiphy.sbi.bolfi.BOLFI(distance, prior, distance_kernel='exp', acquisition='LCB', learn_log_dist=False, bounds=None, param_names=None, verbose=True)[source]

Bayesian Optimisation for Likelihood-Free Inference.

Parameters:

  • distance (callable) – distance(theta) -> float: simulate at theta and return the discrepancy to the observed data.

  • prior (list of (low, high), dict name -> (low, high), or prior object) – Bounds are converted to a UniformPrior. A prior object must expose mins/maxs unless bounds is given.

  • distance_kernel ({"exp", "gaussian"} or callable) – Maps the discrepancy to a log-likelihood. A callable must have signature log_kernel(d) -> log L.

  • acquisition ({"LCB", "EI", "PI"} or callable) – Acquisition function choosing where to simulate next; see psiphy.utils.bayesian_opt. "LCB" follows Gutmann & Corander (2016).

  • learn_log_dist (bool) – Model log d instead of d (helps when d spans orders of magnitude).

  • bounds (list of (low, high), optional) – Search space for the optimisation; defaults to the prior bounds.

  • param_names (list of str, optional)

  • verbose (bool)

learn_likelihood(n_calls=100, n_initial_points=None, batch_size=1, filename=None, reset_model=False, random_state=None, n_candidates=None, **acq_kwargs)[source]

Learn the discrepancy surrogate with Bayesian optimisation.

Parameters:

  • n_calls (int) – Number of new distance evaluations (including initial design points).

  • n_initial_points (int, optional) – Size of the Latin-hypercube initial design; default 5 * n_dim. Points already loaded from filename count towards it.

  • batch_size (int) – Points proposed per optimisation round (kriging believer). The points of one batch are independent, so their simulations can run in parallel; they are currently evaluated in sequence.

  • filename (str, optional) – Pickle file to resume from (unless reset_model) and save to.

  • reset_model (bool) – Ignore an existing filename.

  • random_state (int, optional)

  • n_candidates (int, optional) – Random candidates scored per pick (default 1000 * n_dim).

  • **acq_kwargs – Acquisition options, e.g. kappa (LCB) or xi (EI/PI).

Return type:

self

Draw equal-weight posterior samples from the synthetic likelihood.

Parameters:

  • n_samples (int)

  • method ({"MCMC", "NestedSampling", "IS", "SMC"}) – "MCMC" uses MHSampler (kwargs: n_walkers, n_burn, filename, plus sampler options); "NestedSampling" uses NestedSampler (kwargs: backend, n_live, dlogz, …); "IS" uses importance sampling with the prior as proposal; "SMC" uses likelihood-tempered SMC().

Framework-agnostic prior specifications.

Every prior exposes the same interface so it can be passed to the importance sampling / SMC routines, MCMC samplers, nested samplers (via BasePrior.prior_transform()) and, through the conversion helpers, to scipy, torch and sbi.

Examples

>>> prior = UniformPrior({'mu': (-5, 5), 'sigma': (0.1, 5)})
>>> theta = prior.sample(1000)                  # (1000, 2)
>>> lp = prior.log_prob(theta)                  # (1000,)
>>> theta = prior.prior_transform(np.random.rand(2))   # unit cube -> theta
class psiphy.utils.prior.BasePrior[source]

Common interface for all priors.

Subclasses implement sample(), log_prob() and, where it exists in closed form, prior_transform().

log_prob accepts a single point of shape (ndim,) (returns a float) or a batch of shape (n, ndim) (returns an array of shape (n,)).

Bayesian-optimisation helpers built on scikit-learn Gaussian processes.

Acquisition functions return values to maximise. Each takes the candidate points, a fitted GaussianProcessRegressor, the incumbent y_best and a minimize flag stating whether the underlying objective is minimised (e.g. a BOLFI discrepancy) or maximised (e.g. an LFIRE posterior).

Examples

>>> gpr = GaussianProcessRegressor(Matern(nu=2.5), normalize_y=True).fit(X, y)
>>> x_next = propose_location(gpr, bounds, acquisition="EI", X_sample=X, y_sample=y)
>>> batch = propose_location(gpr, bounds, acquisition="LCB", X_sample=X, y_sample=y, batch_size=4)

psiphy.utils.bayesian_opt.propose_location(gpr, bounds, acquisition='EI', X_sample=None, y_sample=None, batch_size=1, minimize=True, n_candidates=None, n_restarts=5, random_state=None, **acq_kwargs)[source]

Propose the next point(s) to evaluate.

Parameters:

  • gpr (fitted sklearn GaussianProcessRegressor)

  • bounds (array-like, shape (d, 2)) – Search box, in the same coordinates the GP was fitted in.

  • acquisition ({"EI", "PI", "LCB", "UCB"} or callable) – A callable must have signature acq(X, gpr, y_best, minimize, **acq_kwargs) and return values to maximise.

  • X_sample (array-like) – Evaluated points. Needed for EI/PI (incumbent) and for batch_size > 1.

  • y_sample (array-like) – Evaluated points. Needed for EI/PI (incumbent) and for batch_size > 1.

  • batch_size (int) – Number of points to return. Points after the first are chosen by the kriging-believer heuristic: each chosen point is added to the GP with its predicted mean as a fantasy observation, which shrinks the uncertainty there and pushes the next pick elsewhere. Use this to run several simulations in parallel per round.

  • minimize (bool) – Whether the objective modelled by the GP is minimised.

  • n_candidates (int, optional) – Random candidates scored per pick (default 1000 * d).

  • n_restarts (int) – Best candidates polished with L-BFGS-B.

  • random_state (int or numpy Generator, optional)

  • **acq_kwargs – Passed to the acquisition (xi for EI/PI, kappa for LCB/UCB).

Return type:

np.ndarray, shape (batch_size, d)

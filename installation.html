Installation

psiphy requires Python 3.9 or newer.

From PyPI

pip install psiphy

The core install covers priors, importance sampling and sequential Monte Carlo, likelihood-free inference (BOLFI, LFIRE, rejection ABC), Fisher forecasting and the plotting tools.

Optional dependencies

Some samplers rely on external packages, grouped as extras:

development

 
pip install "psiphy[mcmc]"          # one extra
pip install "psiphy[mcmc,sbi]"      # several

MHSampler can store chains in HDF5 files (filename=), which needs h5py.

Development version

The latest version from GitHub:

pip install git+https://github.com/sambit-giri/psiphy.git

For development, clone the repository and install it in editable mode with all extras:

git clone https://github.com/sambit-giri/psiphy.git
cd psiphy
pip install -e ".[dev]"

Check the installation:

import psiphy
print(psiphy.__version__)
